# Aprendizaje de Python

Repositorio de práctica personal. **Estado actual:** todavía no incluye
ejercicios ni un proyecto ejecutable.

## Ruta de aprendizaje propuesta

- Variables, tipos y operaciones.
- Condicionales y bucles.
- Funciones y manejo de errores.
- Lectura de archivos y módulos.
- Un programa pequeño con instrucciones y pruebas.

Cada ejercicio nuevo debe explicar qué practica, cómo ejecutarlo y un ejemplo
de entrada y salida. Cuando exista código, se documentará la versión de Python
probada y cualquier dependencia necesaria.

## Registro

Aún no hay avances documentados. Añadir aquí cada ejercicio al completarlo,
junto con una dificultad encontrada y lo aprendido.
